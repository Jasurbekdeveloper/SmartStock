# Hisobla — reklama sayti

SmartStock (Hisobla) dasturini mijozlarga tanishtiruvchi statik sayt. Build kerak emas — oddiy HTML/CSS/JS.

- `index.html` — sahifa (o'zbekcha matn shu yerda)
- `main.js` — rus va ingliz tarjimalari, `CONTACT` (telefon, Telegram) — e'lon qilishdan oldin to'g'rilang
- `styles.css` — dizayn, `logo.svg` — logotip

Ko'rish: `index.html` ni brauzerda oching. Joylash: papkani Netlify / GitHub Pages / Firebase Hosting'ga yuklang.
